Publish to GitHub Pages

This file is 100% self-contained! You can host it on GitHub for free in less than 2 minutes:

  1. Create a new repository on GitHub (name it e.g. dancing-doll).
  2. Save this entire code into a single file named index.html.
  3. Upload or push index.html to the main branch.
  4. Go to your repository Settings > Pages.
  5. Under Build and deployment, select Deploy from a branch, select main (or root), and save!
